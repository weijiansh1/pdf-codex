# 报告网页样式

论文与横版报告统一采用白底、衬线正文、无衬线标题、细分隔线和三线表；报告内容与数据由各自工作稿维护。

正文使用 Georgia、宋体和衬线字体回退；标题、目录和表格使用 Segoe UI、微软雅黑。题名居中，章节以字号、段间距和细横线区分层级。画布白底，阅读区外背景 #f7f8fb；正文 #16233a，次要说明 #3a4a63，细线 #c9d3e2，链接/编号 #245a9e。章节不使用大色块和圆角卡片。

表格采用三线表：表头顶部、表头底部、表体末尾为主要横线，其余行用浅线辅助对齐。数值使用等宽数字；单位、图例与图题贴近图表。图表颜色用来区分数据系列，正文仍保留深色文字和白底。

连续论文模板使用840px正文上限和独立目录，窄窗口按可用空间收缩或上下排列。横版模板使用16:9一页布局，图表可使用静态SVG，公式以data-tex声明并在网页中即时渲染。

日常修改直接保存 HTML/CSS；PDF 使用浏览器的打印样式生成。LaTeX 是可选输出，原 TeX 文件作为此次切换前的稿件保留，不跟随 HTML 改字自动同步。
